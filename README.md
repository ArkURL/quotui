# quotui

终端看盘工具：一个二进制、零依赖，盯着自选股的现价。

## 安装

```bash
go build -o quotui .
# 或者
go install github.com/arkurl/quotui@latest
```

## 使用

```bash
quotui                 # 打开 TUI
quotui -once           # 抓一次行情，输出纯文本后退出（适合脚本 / tmux 状态栏）
quotui -config ./c.toml
```

## 快捷键

| 按键 | 作用 |
|---|---|
| ↑ / k、↓ / j | 上下移动 |
| g / G | 跳到首行 / 末行 |
| Enter | 打开详情页（分时 / K 线） |
| c | 详情页内切换 分时 / K 线 |
| p | K 线内切换周期（日/周/月/60分） |
| Esc | 返回列表 |
| r | 立即刷新（1 秒冷却） |
| t | 选择刷新周期（含「仅手动」） |
| 空格 | 暂停 / 继续刷新 |
| s / S | 切换排序字段 / 升降序 |
| a | 搜索并添加自选 |
| d | 删除当前行 |
| J / K | 调整自定义顺序 |
| ? | 帮助 |
| q | 退出 |

## 配置

首次启动会自动生成默认配置，位置遵循系统配置目录：

- macOS：`~/Library/Application Support/quotui/config.toml`
- Linux：`~/.config/quotui/config.toml`

```toml
refresh_seconds = 3       # 3 秒自动刷新；0 表示只用 r 手动刷新
color_scheme = "red_up"   # red_up（A 股习惯，红涨绿跌）或 green_up
sort_by = "order"         # order / pct / amount / code
sort_desc = true
columns = ["code", "name", "price", "chg", "pct", "amount", "turnover"]

[[watchlist]]
  code = "600519"
  market = "sh"           # sh / sz / bj / hk / us
  name = "贵州茅台"
```

`columns` 决定展示哪些列及顺序，可选 `code` / `name` / `price` / `chg` / `pct` / `amount` / `turnover`（`chg` 为涨跌额，`pct` 为涨跌幅）。终端变窄时会自动按「换手 → 成交额 → 涨跌额 → 现价 → 代码」的顺序裁列，名称和涨幅始终保留。

`secid` 字段可选，用于固定港美股的市场编号（如 `105.AAPL`），通过 `a` 键搜索添加时会自动写入。

```
                     │         █       █ │     │   │ │         █ █ █ │

```

- 实体用实心块，影线用竖线；A 股习惯红涨绿跌，`green_up` 主题下互换。
- 每根 K 线占 2 列（实体 + 间隔），宽度不够时降为 1 列；右侧对齐，最新一根贴住右边缘。
- 日线用前复权数据，周/月线会按周期自动回溯足够长的历史再截取最近 120 根。
- 分钟级 K 线只有东财提供，主源不可用时该视图会提示失败，分时不受影响。

## 刷新策略

不想被频繁轮询打扰时，按 `t` 选「仅手动」，此后只在按 `r` 时请求。

- 可选周期：仅手动 / 1 / 2 / 3 / 5 / 10 / 30 / 60 秒，选择后写入配置文件。
- 手动刷新有 1 秒冷却，连按 `r` 会被拦下并给出提示。
- 上一次请求未返回时不会再发新请求。
- 全部市场休市时，自动周期最多降到 30 秒。
- 连续两次请求失败后退避到 30 秒，恢复后自动回到你选的周期。

## 行情来源

东财为主源，腾讯为备用源；任一失败（超时、限流、返回空）自动切换，状态栏显示当前生效的数据源。

| 市场 | 东方财富 `push2` | 腾讯 `qt.gtimg.cn` |
|---|---|---|
| A 股 | 沪 `1.`、深/北 `0.` | `sh` / `sz` / `bj` 前缀 |
| 港股 | `116.` | `hk` 前缀 |
| 美股 | `105/106/107.` | `us` 前缀 |
| 指数 | `1.000001`、`100.HSI` | `sh000001`、`hkHSI` |
| 分时 | `push2his/.../trends2` | `web.ifzq.gtimg.cn/.../minute` |
| K 线 | `push2his/.../kline` | `web.ifzq.gtimg.cn/.../fqkline` |

- 一次请求批量拉全部自选（50 只一批），不会逐支轮询。
- 主源只返回部分标的时，会用备用源补齐缺口，不会拿半成品当成功。
- 某个源连续失败会熔断 30 秒（逐次翻倍，最长 5 分钟），期间直接跳过，避免每轮白撞一次。
- 从备用源拿到的美股交易所编号（`105/106/107`）会写回配置，之后主源也能正确定位。
- 上一轮请求还没返回时跳过本轮，弱网下不会堆积请求。
- 全部市场休市时自动降频到 30 秒。
- 两个都是公开的非官方接口，可能随时限流或变更；`provider.Provider` 抽象下一个新数据源只需实现三个方法。

## 已知限制

- 不支持逐笔 / WebSocket 推送，按秒级快照刷新。
- 交易日判断只看星期和时段，不含法定节假日。
- 涨跌幅、成交额等字段以接口返回为准，仅供参考，不构成投资建议。
